# Go Connector Example

This example shows how to build a Connector in Go using the LIMENORA public SDK.

```go
import (
	"github.com/axisvela/LIMENORA/backend/pkg/limenora"
	"github.com/axisvela/LIMENORA-open/sdk/go/sdk" // placeholder import
)
```

Connector SDK guidance will be added during Wave 2 (Connector SDK milestone).
The public SDK surface lives in the core repository at
`backend/pkg/limenora`.

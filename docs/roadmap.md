# Public Roadmap

- **Wave 0** (now): repository split, SDK, docs, binary release workflow.
- **Wave 1** (3–6 months): governed egress MVP with HTTP/CONNECT and remote MCP; secretless credentials.
- **Wave 2** (6–12 months): webhook/event ingress, connector SDK, HA, observability, control console.
- **Wave 3** (12–18 months): federation, ecosystem connector packs, robot/edge pilot.

Milestones are tracked against the internal product plan in the LIMENORA-ee repository.

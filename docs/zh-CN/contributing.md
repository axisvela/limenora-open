# 贡献指南（中文）

limenora-open 欢迎对 SDK、示例和文档的贡献。

## License 边界

- 本仓库的 SDK、示例和文档为 **Apache-2.0**。
- 运行时改动属于 [limenora](https://github.com/axisvela/limenora) 核心仓库（**AGPL-3.0**）。
- 企业特性属于 [limenora-ee](https://github.com/axisvela/limenora-ee)。

## 如何开始

1. Fork 本仓库。
2. 创建功能分支。
3. 做出修改，涉及行为时补充测试。
4. 提交 Pull Request 并描述改动。

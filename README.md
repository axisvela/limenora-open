# LIMENORA Open

The open face of LIMENORA — Enterprise Agent Integration Gateway.

LIMENORA is the governed north–south integration boundary that connects agents,
workflows, robots and twins to external APIs, MCP servers, events, webhooks and
partner ecosystems without leaking protocols, credentials or trust assumptions into
autonomous runtimes.

This repository (`github.com/axisrobo/LIMENORA-open`) is licensed under Apache-2.0
and contains the official SDK, examples, API specifications, and binary release
information. It does **not** contain the runtime source code, which lives in the
[LIMENORA](https://github.com/axisrobo/LIMENORA) core repository (AGPL-3.0).
